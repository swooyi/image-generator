# 프로젝트 현재 상태

## 목적

이 문서는 현재 구현된 기능, 배포 상태, 남은 작업을 빠르게 확인하기 위한 상태 문서다. 변환 규칙의 자세한 설계는 `docs/transform-architecture.md`를 기준으로 한다.

## 현재 구현된 기능

- 3x3 공식 변환을 지원한다.
- 원본 공식의 역공식을 출력한다.
- 좌우대칭, 전후대칭, 상하대칭을 출력한다.
- 각 대칭 공식의 역공식을 같은 카드 안에 함께 출력한다.
- 출력은 1개 컬럼 카드 목록으로 표시한다.
- 커뮤테이터와 컨쥬게이트 입력을 지원한다.
  - `[X,Y]`는 `X Y X' Y'`로 해석한다.
  - `X:Y`는 `X Y X'`로 해석한다.
  - `X`, `Y`에는 여러 회전과 중첩 축약식을 넣을 수 있다.
- 출력 표시 방식 토글을 지원한다.
  - `축약`: 커뮤테이터와 컨쥬게이트 구조를 가능한 유지한다.
  - `풀어쓰기`: 축약식을 일반 회전열로 확장한다.
- 입력의 줄바꿈을 출력에도 보존한다.
- 각 줄은 독립적으로 변환한다.
- `//`부터 줄 끝까지는 라인 주석으로 처리하고 그대로 출력한다.
- 3x3 공식 부분에서 가독성용 `(`, `)`, `,`, `/`는 공백처럼 처리한다.
- 공식 입력 도움말 팝업을 제공한다.
- Paperlogy 폰트 파일을 `public/fonts/`에 포함하고 CSS에서 `url(...)`로 연결한다.

## 현재 준비 중인 기능

- Square-1 변환기는 아직 구현되지 않았다.
- FTO 변환기는 아직 구현되지 않았다.
- 앱 화면에는 Square-1과 FTO 출력 카드가 표시되지만, 현재는 `변환 규칙 준비 중`으로 안내한다.

## 배포와 저장소 상태

- GitHub 저장소: `https://github.com/swooyi/solution-transfer`
- 배포 시 빌드 명령은 `npm run build`를 사용한다.
- 배포 결과물 폴더는 `dist`다.
- `dist`와 `node_modules`는 저장소에 커밋하지 않는다.
- Paperlogy 폰트는 `public/fonts/`에 포함되어 배포 사이트에서도 로드된다.

## 최근 주요 커밋

- `d563f06 add-readable-separators`
  - GitHub 초기 푸쉬.
  - 3x3 가독성 구분자와 기본 프로젝트 파일을 반영했다.
- `0a72d83 add-commutator-conjugate-and-fonts`
  - 커뮤테이터/컨쥬게이트 입력과 Paperlogy 웹폰트를 반영했다.
- `b2b9b5c preserve-compact-output-toggle`
  - 커뮤테이터/컨쥬게이트 축약 출력 유지와 축약/풀어쓰기 토글을 반영했다.

## 앞으로 할 작업

1. 3x3 변환 검증 강화
   - 커뮤테이터, 컨쥬게이트, 중첩 축약식의 예시 테스트를 추가한다.
   - 대칭과 역공식 조합의 회귀 테스트를 추가한다.

2. FTO 변환기 구현
   - `docs/notation/fto.md`와 `.codex/skills/fto-notation/SKILL.md` 기준으로 파서를 만든다.
   - FTO의 역공식, 좌우대칭, 전후대칭을 구현한다.
   - FTO에 커뮤테이터/컨쥬게이트 축약 입력을 적용한다.

3. Square-1 변환기 구현
   - `docs/notation/square-1.md`와 `.codex/skills/square-1-notation/SKILL.md` 기준으로 파서를 만든다.
   - Square-1은 `/`가 실제 표기이므로 3x3/FTO의 가독성용 `/` 무시 규칙을 적용하지 않는다.

4. 사용자 경험 개선
   - 출력 복사 후 피드백을 추가한다.
   - 잘못된 입력의 오류 위치나 원인을 더 명확히 보여준다.
   - 도움말 문구를 퍼즐 선택에 따라 다르게 보여줄지 검토한다.

5. 배포 정리
   - GitHub Pages, Vercel, Netlify 중 실제 배포 방식을 확정한다.
   - 선택한 배포 방식에 맞는 설정 문서를 추가한다.
