# 3x3 행렬 기반 변환 기준

## 목적

3x3 공식 변환기를 추후 행렬 기반 방식으로 전환하기 위한 기준 문서다.

기존 변환기는 토큰별 대칭 매핑을 직접 들고 있어도 되지만, 행렬 기반 변환에서는 각 면을 3차원 방향 벡터로 정의하고, 대칭 행렬을 적용해서 변환 결과를 계산한다.

## 좌표계

3x3 큐브의 기본 면 방향은 다음 3x1 벡터로 확정한다.

```text
R = [ 1,  0,  0]
L = [-1,  0,  0]
U = [ 0,  1,  0]
D = [ 0, -1,  0]
F = [ 0,  0,  1]
B = [ 0,  0, -1]
```

축 이름으로 쓰면 다음과 같다.

```text
+x = R
-x = L
+y = U
-y = D
+z = F
-z = B
```

## 텍스트 입력 기준

사용자 입력은 공식 표기를 그대로 사용한다.

```text
R U R' U'
```

변환기 내부에서는 각 토큰을 다음 정보로 파싱한다.

```text
R' -> face: R, vector: [1, 0, 0], suffix: '
U2 -> face: U, vector: [0, 1, 0], suffix: 2
F  -> face: F, vector: [0, 0, 1], suffix: 없음
```

행렬 테스트나 디버그 입력이 필요하면 다음 형식을 허용할 수 있다.

```text
R
[1,0,0]
+x
```

세 입력은 모두 같은 방향으로 정규화한다.

```text
R = [1, 0, 0] = +x
```

일반 UI에서는 `R L U D F B` 면 문자를 우선 사용하고, 벡터 직접 입력은 개발용 또는 디버그용으로 둔다.

## 대칭 행렬

좌우대칭은 x축 부호를 반전한다.

```text
leftRight =
[-1,  0,  0]
[ 0,  1,  0]
[ 0,  0,  1]
```

상하대칭은 y축 부호를 반전한다.

```text
upDown =
[ 1,  0,  0]
[ 0, -1,  0]
[ 0,  0,  1]
```

전후대칭은 z축 부호를 반전한다.

```text
frontBack =
[ 1,  0,  0]
[ 0,  1,  0]
[ 0,  0, -1]
```

## 면 회전 변환

면 회전은 다음 순서로 변환한다.

```text
토큰 파싱
  -> 면을 벡터로 변환
  -> 대칭 행렬 적용
  -> 결과 벡터를 면 문자로 변환
  -> 회전 방향 보정
```

예를 들어 좌우대칭에서 `R`은 다음처럼 처리한다.

```text
R = [1, 0, 0]
leftRight * [1, 0, 0] = [-1, 0, 0]
[-1, 0, 0] = L
```

대칭 행렬은 거울 변환이므로 90도 회전 방향을 반대로 바꾼다.

```text
접미사 없음 -> '
'           -> 접미사 없음
2           -> 2
```

따라서 최종 결과는 다음과 같다.

```text
R  -> L'
R' -> L
R2 -> L2
```

## 대칭별 예시

좌우대칭:

```text
R  -> L'
L  -> R'
U  -> U'
D' -> D
F2 -> F2
```

상하대칭:

```text
U  -> D'
D  -> U'
R  -> R'
L' -> L
F2 -> F2
```

전후대칭:

```text
F  -> B'
B  -> F'
R  -> R'
L' -> L
U2 -> U2
```

## 전체 큐브 회전

전체 큐브 회전 `x y z`는 면 위치가 아니라 회전축을 뜻한다.

대칭 행렬 아래에서 회전축은 일반 벡터가 아니라 축 회전 방향으로 처리한다. 거울대칭에서는 행렬식이 `-1`이므로 다음처럼 계산한다.

```text
rotatedAxis = determinant(matrix) * matrix * axis
```

이 기준을 적용하면 기존 대칭 규칙과 일치한다.

좌우대칭:

```text
x  -> x
y  -> y'
z  -> z'
```

상하대칭:

```text
x  -> x'
y  -> y
z  -> z'
```

전후대칭:

```text
x  -> x'
y  -> y'
z  -> z
```

## wide move

wide move는 바깥 면 방향을 기준으로 같은 행렬 규칙을 적용하고, `w`를 유지한다.

```text
Rw  -> Lw'
Rw' -> Lw
Rw2 -> Lw2
```

소문자 wide 입력은 먼저 WCA 스타일로 정규화한 뒤 변환한다.

```text
r -> Rw -> Lw'
u -> Uw -> Uw'
```

## slice move

slice move는 프로젝트의 3x3 표기법 기준을 따른다.

```text
M = L 방향으로 움직이는 가운데 슬라이스
E = D 방향으로 움직이는 적도 슬라이스
S = F 방향으로 움직이는 스탠딩 슬라이스
```

행렬 기반으로 전환할 때는 각 slice move를 기준 방향 벡터에 연결한 뒤, 면 회전과 같은 대칭 규칙을 적용한다.

```text
M 기준 방향 = L = [-1, 0, 0]
E 기준 방향 = D = [0, -1, 0]
S 기준 방향 = F = [0, 0, 1]
```

단, 출력 토큰은 `M E S` 집합으로 다시 정규화해야 한다.

## 구현 메모

- 입력 문자열을 직접 치환하지 않고 토큰으로 파싱한 뒤 변환한다.
- 벡터와 행렬은 정수 `-1`, `0`, `1`만 사용한다.
- 변환 결과 벡터가 기본 6면 중 하나가 아니면 오류로 처리한다.
- 대칭의 역공식은 `inverse(mirror(input))` 순서로 계산한다.
- 줄바꿈과 라인 주석 처리 규칙은 기존 변환 엔진 기준을 유지한다.

## 사용자 시점 변환

사용자 시점 변환은 같은 공식의 기호를 다른 시점 기준으로 다시 쓰기 위한 변환이다.

`{X,Y}`는 기존 `X`면이 새 `U`면으로 가고, 기존 `Y`면이 새 `F`면으로 가는 시점 변환으로 정의한다.

```text
{X,Y}: X -> U, Y -> F
```

예를 들어 `{U,F}`는 기존 시점과 같은 변환이다.

```text
{U,F}: U -> U, F -> F
```

`{F,U}`는 기존 `F`면이 새 `U`면으로 가고, 기존 `U`면이 새 `F`면으로 가는 변환이다.

```text
{F,U}: F -> U, U -> F
```

`{R,B}`는 기존 `R`면이 새 `U`면으로 가고, 기존 `B`면이 새 `F`면으로 가는 변환이다.

```text
{R,B}: R -> U, B -> F
```

`X`, `Y`는 서로 인접한 면이어야 한다. 같은 면 또는 반대면 쌍은 불가능하다.

```text
불가능한 예:
{R,R}
{R,L}
{L,R}
{U,D}
{D,U}
{F,B}
{B,F}
```

행렬은 기존 문서와 같은 기준으로 왼쪽에서 곱한다.

```text
newVector = matrix * oldVector
```

세 번째 축은 우수 좌표계를 유지하도록 다음 기준으로 결정한다.

```text
cross(X,Y) -> cross(U,F)
```

따라서 사용자 시점 변환 행렬은 모두 `determinant = 1`인 회전 행렬이다.

대표 예시는 다음과 같다.

```text
{U,F} =
[ 1,  0,  0]
[ 0,  1,  0]
[ 0,  0,  1]

{F,U} =
[-1,  0,  0]
[ 0,  0,  1]
[ 0,  1,  0]

{R,B} =
[ 0,  1,  0]
[ 1,  0,  0]
[ 0,  0, -1]
```

가능한 `{X,Y}` ordered pair는 24개다.

```text
{R,U} = [[ 0,  0,  1], [ 1,  0,  0], [ 0,  1,  0]]
{R,D} = [[ 0,  0, -1], [ 1,  0,  0], [ 0, -1,  0]]
{R,F} = [[ 0, -1,  0], [ 1,  0,  0], [ 0,  0,  1]]
{R,B} = [[ 0,  1,  0], [ 1,  0,  0], [ 0,  0, -1]]

{L,U} = [[ 0,  0, -1], [-1,  0,  0], [ 0,  1,  0]]
{L,D} = [[ 0,  0,  1], [-1,  0,  0], [ 0, -1,  0]]
{L,F} = [[ 0,  1,  0], [-1,  0,  0], [ 0,  0,  1]]
{L,B} = [[ 0, -1,  0], [-1,  0,  0], [ 0,  0, -1]]

{U,R} = [[ 0,  0, -1], [ 0,  1,  0], [ 1,  0,  0]]
{U,L} = [[ 0,  0,  1], [ 0,  1,  0], [-1,  0,  0]]
{U,F} = [[ 1,  0,  0], [ 0,  1,  0], [ 0,  0,  1]]
{U,B} = [[-1,  0,  0], [ 0,  1,  0], [ 0,  0, -1]]

{D,R} = [[ 0,  0,  1], [ 0, -1,  0], [ 1,  0,  0]]

{F,L} = [[ 0, -1,  0], [ 0,  0,  1], [-1,  0,  0]]

{F,D} = [[ 1,  0,  0], [ 0,  0,  1], [ 0, -1,  0]]

{B,R} = [[ 0, -1,  0], [ 0,  0, -1], [ 1,  0,  0]]
{B,L} = [[ 0,  1,  0], [ 0,  0, -1], [-1,  0,  0]]
{B,U} = [[ 1,  0,  0], [ 0,  0, -1], [ 0,  1,  0]]

```
