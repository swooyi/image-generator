# 3x3 표기법 구현 기준

## 지원 토큰

기본 면 회전은 Singmaster 표기를 사용한다.

```text
U D F B R L
U' D' F' B' R' L'
U2 D2 F2 B2 R2 L2
```

접미사는 다음처럼 처리한다.

```text
접미사 없음 = 시계방향 90도
'           = 반시계방향 90도
2           = 180도
```

## 선택 지원 토큰

전체 큐브 회전은 다음 토큰을 지원한다.

```text
x x' x2
y y' y2
z z' z2
```

wide move는 WCA 스타일을 정규 표기로 사용한다.

```text
Uw Dw Fw Bw Rw Lw
Uw' Dw' Fw' Bw' Rw' Lw'
Uw2 Dw2 Fw2 Bw2 Rw2 Lw2
```

소문자 wide 표기는 입력 별칭으로 허용하고, 정규 출력에서는 WCA 스타일로 출력한다.

```text
u -> Uw
d -> Dw
f -> Fw
b -> Bw
r -> Rw
l -> Lw
```

slice move는 다음 토큰을 지원한다.

```text
M M' M2
E E' E2
S S' S2
```

## 파싱 기준

- 가장 긴 토큰을 먼저 매칭한다.
- 3x3 토큰은 대소문자를 구분한다.
- 회전 사이의 공백은 선택 사항이다.
- `RUR'U'` 같은 공백 없는 입력은 `R U R' U'`로 파싱한다.
- 쉼표는 요구하지 않으며 입력에 포함되면 오류로 처리한다.
- 호환 입력으로 `R'2`는 `R2`, `R3`는 `R'`로 정규화한다.
- `R''`, `R22`, `R23`, `R32` 같은 접미사 중복 또는 잘못된 접미사는 거부한다.

## 정규 출력

- 면, slice, 전체 회전 기호는 표준 대소문자를 유지한다.
- wide move는 기본적으로 `Uw`, `Rw` 같은 WCA 스타일로 출력한다.
- 소문자 wide 입력은 파싱 후 정규 출력에서 대문자 `Xw` 형태로 변환한다.
- 접미사 호환 입력인 `3`과 `'2`는 출력에서 보존하지 않고 각각 `'`, `2`로 출력한다.

## 변환 구현 메모

- 역공식은 토큰 순서를 뒤집고 각 토큰의 방향을 반전한다.
- `2` 접미사는 방향 반전 후에도 `2`를 유지한다.
- `유지`는 면 이름과 방향을 모두 그대로 둔다는 뜻이다.

## 대칭 매칭 규칙

방향 반대 규칙은 다음과 같다.

```text
접미사 없음 -> '
'           -> 접미사 없음
2           -> 2
```

wide move는 `w`를 유지하고, 앞의 면을 같은 대칭 규칙으로 처리한다.

```text
좌우대칭 Rw  -> Lw'
좌우대칭 Uw  -> Uw'
좌우대칭 Fw2 -> Fw2
```

### 좌우대칭

다음 토큰은 방향만 반대로 바꾼다.

```text
U D F B S E
```

다음 토큰은 서로 교대하면서 방향을 반대로 바꾼다.

```text
R <-> L
```

다음 토큰은 그대로 유지한다.

```text
M
```

전체 큐브 회전은 다음처럼 처리한다.

```text
x = 유지
y = 방향 반대
z = 방향 반대
```

예시는 다음과 같다.

```text
U   -> U'
D'  -> D
F2  -> F2
R   -> L'
L   -> R'
M'  -> M'
Rw  -> Lw'
y   -> y'
```

### 전후대칭

다음 토큰은 방향만 반대로 바꾼다.

```text
U D R L M E
```

다음 토큰은 서로 교대하면서 방향을 반대로 바꾼다.

```text
F <-> B
```

다음 토큰은 그대로 유지한다.

```text
S
```

전체 큐브 회전은 다음처럼 처리한다.

```text
x = 방향 반대
y = 방향 반대
z = 유지
```

예시는 다음과 같다.

```text
U   -> U'
R'  -> R
F   -> B'
B2  -> F2
S   -> S
z'  -> z'
```

### 상하대칭

다음 토큰은 방향만 반대로 바꾼다.

```text
F B R L M S
```

다음 토큰은 서로 교대하면서 방향을 반대로 바꾼다.

```text
U <-> D
```

다음 토큰은 그대로 유지한다.

```text
E
```

전체 큐브 회전은 다음처럼 처리한다.

```text
x = 방향 반대
y = 유지
z = 방향 반대
```

예시는 다음과 같다.

```text
F   -> F'
R2  -> R2
U   -> D'
D'  -> U
E   -> E
S   -> S'
x   -> x'
y'  -> y'
```
