# FTO 표기법 구현 기준

## 지원 토큰

FTO는 8개 기본 면 표기를 사용한다.

```text
U F L R B BL BR D
U' F' L' R' B' BL' BR' D'
```

각 면 회전은 120도 회전이다.

```text
접미사 없음 = 시계방향 120도
'           = 반시계방향 120도
```

반대면 쌍은 다음과 같다.

```text
U opposite D
F opposite B
R opposite BL
L opposite BR
```

FTO 표기는 색상과 무관하며 현재 방향의 위치 기준으로 해석한다.

## 방향 기준

FTO 표기에는 두 가지 방향 기준이 있다.

```text
CIF = corner in front
EIF = edge in front
```

방향 기준이 명시되지 않은 외부 문서는 CIF를 기본값으로 둔다. 공식이 CIF 기준인지 EIF 기준인지는 파싱 결과와 별도 메타데이터로 함께 다룬다.

## Slice 토큰

프로젝트 표기는 다음 4개 slice를 사용한다.

```text
Us = U-D 사이 slice
Fs = F-B 사이 slice
Rs = R-BL 사이 slice
Ls = L-BR 사이 slice
```

slice 토큰은 일반 면 토큰과 구분해서 파싱한다.

## Wide 토큰

정규 wide 표기는 face name 뒤에 `w`를 붙인다.

```text
Uw Fw Lw Rw Bw BLw BRw Dw
Uw' Fw' Lw' Rw' Bw' BLw' BRw' Dw'
```

소문자 wide 표기는 정규 표기로 사용하지 않는다. 외부 호환 입력으로 허용하는 경우에는 `r`을 `Rw`, `u'`를 `Uw'`처럼 정규화한다.

## CIF 축약 토큰

CIF 상태에서는 다음 축약 토큰을 입력으로 허용할 수 있다.

```text
S  = R' L R L'
S' = L R' L' R

H  = R B' R' B
H' = B' R B R'
```

이 축약 토큰은 CIF 방향 기준 컨텍스트에서만 사용한다. EIF 컨텍스트에서는 별도 정의 없이 물리 회전으로 해석하지 않는다.

## 선택 지원 토큰

FTO `2` 접미사는 호환 입력으로만 선택 지원한다.

```text
U2 F2 L2 R2 B2 BL2 BR2 D2
```

프로젝트 기본 정책은 정규 출력에서 `2` 접미사를 사용하지 않는 것이다. `X2`를 허용하는 경우 물리 효과는 `X'`와 같다.

## 파싱 기준

- 가장 긴 토큰을 먼저 매칭한다.
- `BLw`, `BRw`, `BL`, `BR`이 `B`와 분리되지 않도록 주의한다.
- 일반 회전 토큰 사이에는 공백을 허용한다.
- 호환 모드가 꺼져 있으면 `U2`, `BL2`, `r`, `u'`는 거부한다.
- `M`, `E`, `DF`처럼 존재하지 않는 면 이름은 거부한다.

## 정규 출력

- wide move는 반드시 `Xw` 형식으로 출력한다.
- 소문자 wide 표기는 출력하지 않는다.
- CIF 축약 토큰은 출력 대상이 CIF 축약 보존을 허용할 때만 보존한다.
- CIF 축약 보존을 허용하지 않으면 기본 회전열로 확장한다.

## 변환 구현 메모

FTO v1 출력은 다음 3개를 지원한다.

```text
역공식
좌우대칭
전후대칭
```

상하대칭은 현재 UI에서 표시하지 않는다.

좌우대칭과 전후대칭은 FTO 방향 기준과 면 매핑이 필요하므로, 변환 규칙을 별도 문서 또는 코드 상수로 먼저 확정한 뒤 구현한다.
